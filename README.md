# Site généré automatiquement

Ce dépôt contient un site statique minimal généré automatiquement à partir du CV et de l'analyse des dépôts publics.

Fichiers importants:
- `index.html` — page principale
- `styles.css` — styles
- `cv_alternance_khady.pdf` — CV fourni (copié dans le dépôt)

Pour publier: GitHub Pages est activé automatiquement pour `main` (branche par défaut). Si vous voulez un design différent, dites‑moi quelles modifications faire.
