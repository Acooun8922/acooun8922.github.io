memoireMaster

Monorepo — Plateforme Multi‑tenant de Gestion Universitaire

Technos détectées : React (Vite), TypeScript, Tailwind, Node.js, Express, PostgreSQL, MongoDB, Solidity (Hardhat), Docker & Docker Compose.

Résumé

Ce projet est structuré comme un monorepo contenant les 3 couches principales de l'application :

  • Frontend (`/frontend`) — React.js (Vite) + TypeScript, Tailwind CSS. Interface pour SuperAdmin, Admin Université, Etudiants.
  • Backend (`/backend`) — Node.js + Express.js + TypeScript. PostgreSQL (données relationnelles) et MongoDB (documents, dossiers).
  • Blockchain (`/blockchain`) — Smart Contracts Solidity (Ethereum/Polygon) pour ancrage de documents (hash).

Infrastructure

Conteneurisation avec Docker & Docker Compose. Fichiers utiles : `docker-compose.yml`, `package.json`.
