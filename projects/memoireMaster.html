memoireMaster

Monorepo — Plateforme Multi-Tenant de Gestion Universitaire

Projet full-stack de master : plateforme complète avec smart contracts blockchain pour sécurité et traçabilité.

🏗️ Architecture Monorepo

Le projet est structuré en 3 couches principales + infrastructure partagée :

┌─────────────────────────────────────────────────────────────┐
│                    FRONTEND (React/Vite)                     │
│  SuperAdmin  │  Admin Univ  │  Étudiants  │  Enseignants    │
└──────────────────────┬──────────────────────────────────────┘
                       │  REST API
┌──────────────────────┴──────────────────────────────────────┐
│           BACKEND (Node.js/Express + TypeScript)            │
│     PostgreSQL        │        MongoDB        │  JWT Auth    │
└──────────────────────┬──────────────────────────────────────┘
                       │  JSON RPC
┌──────────────────────┴──────────────────────────────────────┐
│         BLOCKCHAIN (Solidity/Hardhat/Ethereum)              │
│  Document Hash  │  Diplômes  │  Certifications Anchoring   │
└─────────────────────────────────────────────────────────────┘
  • Frontend (`/frontend`) — React.js (Vite) + TypeScript + Tailwind CSS
    • Interfaces multi-rôles : SuperAdmin, Admin Université, Étudiants, Enseignants
    • Dashboards avec visualisations en temps réel
    • Authentification JWT, gestion des permissions
  • Backend (`/backend`) — Node.js + Express.js + TypeScript
    • PostgreSQL pour données relationnelles (utilisateurs, inscriptions, résultats)
    • MongoDB pour données non-structurées (documents, archives)
    • APIs REST, gestion d'authentification, validation des données
  • Blockchain (`/blockchain`) — Smart Contracts Solidity
    • Hardhat pour développement et testing
    • Déploiement Ethereum/Polygon
    • Ancrage immutable de hashes de documents

✨ Fonctionnalités principales

  • Gestion multi-université : chaque université a son espace isolé (multi-tenant)
  • Inscriptions & Résultats : parcours complet étudiant (inscription → validation → résultats)
  • Blockchain : validation immutable des dossiers importants (diplômes, certifications)
  • Authentification avancée : JWT, OAuth2 (intégration SSO université)
  • Exports & Reports : génération PDF, statistiques académiques
  • Notifications temps réel : email, SMS, notifications in-app

💻 Stack technique complet

React 18+ Vite TypeScript Tailwind CSS Node.js Express PostgreSQL MongoDB Solidity Hardhat Docker Docker Compose JWT WebSocket

🚀 Déploiement & Infrastructure

  • Conteneurisation complète avec Docker & Docker Compose
  • Services orchestrés (frontend, backend, postgres, mongodb, blockchain)
  • Prêt pour déploiement K8s (inclut manifests)
  • CI/CD avec GitHub Actions

📊 Cas d'usage académique

  • Universités privées multi-campus
  • Cursus mixte (présentiel + distanciel)
  • Intégration avec LMS (Moodle, Canvas)
  • Traçabilité réglementaire et conformité CNIL

Exigences & Installation

Prérequis :

  • Node.js 16+ et npm/yarn
  • Docker & Docker Compose
  • PostgreSQL 12+
  • MongoDB 4.4+

Installation rapide :

git clone https://github.com/arame7/memoireMaster.git
cd memoireMaster

# Démarrer tous les services avec Docker Compose
docker-compose up -d

# Ou en développement local
npm install
npm run dev
