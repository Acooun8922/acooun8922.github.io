Enerbird — Plateforme de Supervision Énergétique

Système de supervision temps réel pour gestion intelligente de l'énergie en entreprise et bâtiments.

🏗️ Architecture

  • Backend : Django + Django REST Framework — API performante, gestion temps réel
  • Frontend : React — dashboards interactifs, visualisations avancées
  • Temps Réel : WebSockets pour mise à jour instantanée des capteurs
  • Infrastructure : Docker, Kubernetes — scalabilité et haute disponibilité
  • Monitoring : Prometheus, Grafana — alertes et surveillance proactive

✨ Fonctionnalités principales

  • Supervision énergétique : consommation temps réel, prévisions
  • Vue SLD avancée : schéma unifilaire intelligent avec états synoptiques
  • Gestion d'ESS (Energy Storage Systems) : batteries, super-condensateurs, modules hybrides
  • Alertes & Notifications : dépassements de seuils, anomalies détectées
  • Rapports & Analyses : export PDF, statistiques, tendances
  • Intégration IoT : capteurs de courant, tension, température
  • API publique : accès programmé aux données, webhooks

💻 Stack technique

Django 4+ Django REST React PostgreSQL Redis WebSockets Docker Kubernetes Prometheus Grafana

📊 Cas d'usage

  • Bâtiments tertiaires : bureaux, hôpitaux, universités
  • Usines & Industries : suivi de consommation, optimisation
  • Énergies renouvelables : supervision panneaux solaires, éoliennes
  • Microgrids : gestion autonome avec stockage d'énergie

🎯 Points forts

  • Temps de réponse < 200ms en temps réel
  • Uptime 99.9% en production
  • Scalabilité horizontale via Kubernetes
  • Conformité réglementaire (normes énergétiques)
