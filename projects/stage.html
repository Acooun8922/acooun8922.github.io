Plateforme de Gestion des Stages

Application web complète pour coordonner les stages : offres, candidatures, suivi et évaluation.

🏗️ Architecture

  • Backend : Laravel 9+ (PHP 8+) — API REST, validation, authentification JWT
  • Frontend : React/Vue + Tailwind + Vite — interface moderne et responsive
  • Infrastructure : Docker & Docker Compose — déploiement et dev en conteneur
  • Base de données : PostgreSQL ou MySQL (configurable via .env)

✨ Fonctionnalités principales

  • Espace étudiants : recherche et candidature à des offres
  • Espace entreprises : publication d'offres, gestion des candidatures
  • Suivi de stage : activités, tâches, évaluations en temps réel
  • Génération de rapports et attestations PDF
  • Système de notifications (email, in-app)

💻 Stack technique

Laravel PHP 8+ React/Vue Tailwind CSS Vite Docker PostgreSQL PHPUnit

📋 Exigences & Installation

Prérequis :

  • Docker & Docker Compose
  • Node.js 16+ (frontend)
  • PHP 8+ (backend)
  • PostgreSQL 12+

Démarrage rapide :

git clone https://github.com/arame7/stage.git
cd stage

docker-compose up -d
# Accédez à http://localhost:8000
