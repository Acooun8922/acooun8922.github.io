Projet Enerbird

Enerbird est une plateforme de supervision énergétique en temps réel pour le tertiaire et l'industrie : consommation, alertes, rapports de conformité.

Rôle

  • Fonctionnalités backend (Django + DRF)
  • Dashboards et visualisations temps réel (React)
  • Optimisation des performances des services
  • Intégration de données IoT / parsing
  • Déploiement et monitoring (Docker, Kubernetes)

Stack

Django Django REST Framework React PostgreSQL Redis Docker Kubernetes IoT

Impact

Contribution à une solution de gestion énergétique : meilleure lisibilité des consommations et appui à la conformité réglementaire.
