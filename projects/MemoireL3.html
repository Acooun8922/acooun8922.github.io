Plateforme de Gestion Académique — Laravel/PHP

Full-stack académique avec dashboard avancé, gestion des étudiants et visualisations en temps réel.

Architecture

  • Backend : Laravel 9+ (PHP 8+) — RESTful API, authentification, gestion des rôles
  • Frontend : Tailwind + Vite — dashboard responsive, composants interactifs
  • Data Viz : Chartist.js, D3.js — graphiques temps réel, rapports dynamiques
  • Testing : PHPUnit — test unitaires et d'intégration

Fonctionnalités principales

  • Gestion complète des inscriptions et résultats académiques
  • Tableaux de bord avec visualisations avancées (D3, Chartist)
  • Authentification sécurisée, gestion des permissions par rôle
  • Export de rapports (PDF, Excel)

Stack technique

PHP 8+ Laravel Tailwind CSS Vite D3.js Chartist PHPUnit
