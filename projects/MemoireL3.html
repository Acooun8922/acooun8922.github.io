MemoireL3

Application Laravel / PHP

Technos détectées : PHP, Laravel, Composer, Tailwind, Vite, Chartist, D3.

Résumé

Projet basé sur Laravel — back-end PHP (présence de `artisan`, `composer.json`, `phpunit.xml`). Le projet contient aussi des plugins JS (Chartist, D3) dans `public/admin/assets`.

Notes

Le dépôt contient `composer.lock` indiquant un ensemble important de dépendances PHP et des assets JS pour les tableaux de bord/visualisations.
