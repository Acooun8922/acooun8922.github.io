secu2 Shop — E-commerce Frontend

Application e-commerce React moderne avec panier, filtres produits et paiement intégré.

🏗️ Architecture

  • Frontend : React 18+ (TypeScript) avec Create React App
  • UI : Tailwind CSS, composants réutilisables
  • State : Redux ou Context API pour la gestion d'état
  • Routing : React Router v6 pour navigation client

✨ Fonctionnalités principales

  • Catalogue de produits avec filtres (catégorie, prix, notes)
  • Panier persistant (localStorage/sessionStorage)
  • Système de favoris et wishlist
  • Fiche produit détaillée avec images et avis
  • Processus de checkout simplifié
  • Intégration Stripe/PayPal (démo)

💻 Stack technique

React 18+ TypeScript Tailwind CSS Redux React Router Axios Jest

📦 Scripts disponibles

  • yarn start — Lancer le dev server
  • yarn build — Build de production (optimisé)
  • yarn test — Lancer les tests Jest
